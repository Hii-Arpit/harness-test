# Folders

Folders organize resource budgets on the **Resource budgets** tab. Users who have access to a folder can view the budgets inside it.

{% hint style="info" %}
**Budget groups**

Budget groups are not available on this Budgets page. Use folders to organize resource budgets.
{% endhint %}

---

## What you will learn from this topic

* How to open the Folders panel on Resource budgets
* How to create a folder and move a budget into one
* How folder access affects who can view a budget and its cost view

---

## Before you begin

* At least one resource budget, or permission to create one. Go to [Create a resource budget](create-a-resource-budget.md) to create a budget.

---

## Open the Folders panel

In the left navigation, select **Cloud & AI Costs**, then select **Budgets**.

Select the **Resource budgets** tab.

The **Folders** panel lists **All budgets** and your folders. Select a folder to show the budgets in it. Select **All budgets** to return to the full list.

Use **Search folders** to find a folder by name.

{% hint style="info" %}
**Folder access**

To view a resource budget and its cost view, you need access to the folder that contains the budget. When you save a budget to the **Default** folder, users need access to that folder to view the budget and its cost view.
{% endhint %}

---

## Create a folder

Click **New folder**, enter a folder name, then save the folder.

You can also create a folder from **Save budget to folder** when you create a resource budget. Go to [Create a resource budget](create-a-resource-budget.md) for that step.

---

## Move a budget to a folder

On the **Resource budgets** list, click **Show more actions** on the budget row, then select **Move to folder**.

Select the destination folder.

You can also choose a folder when you create the budget. Go to [Manage resource budgets](manage-resource-budgets.md) for other row actions.
