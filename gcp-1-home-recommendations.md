## GCP recommendations

CACM supports Governance recommendations for GCP.

For more information, go to [Asset Governance recommendations](../../../cost-governance/asset-governance/recommendations.md) for a complete list of supported governance recommendations.

## GCP resource coverage (examples)

* Compute Engine instances
* Cloud Storage buckets
* App Engine applications
* Cloud SQL instances
* Cloud IAM policies

For a comprehensive list of all supported GCP resources, go to [GCP Resource Reference - Cloud Custodian documentation](https://cloudcustodian.io/docs/gcp/resources/index.html).
